# 3D 数学宇宙：全模型自主行动与黎曼威慑龙行为层规格方案

> 版本：v1.0（2026-11-25）
> 范围：M01–M40 共 114 个模型个体 + 黎曼猜想巨兽（RiemannLeviathan）
> 状态：Phase A/B/C 已实现并通过门禁（2026-11-25）

## 1. 目标

1. **全模型自主行动**：114 个个体在现有开普勒轨道骨架上叠加独立行为层，具备变速、游荡、变轨意图与玩家反应，不再是匀速贴轨道滑行的“布景”。
2. **个体差异可感知**：每个个体的速度基线、速度波动、游荡幅度、反应半径、姿态增益均由 `(modelType, category, orbit.seed)` 确定性生成，同一实例每次启动一致，不同实例互不相同。
3. **黎曼巨兽像龙**：在莫比乌斯导轨上叠加脊柱蜿蜒、俯冲爬升、变速冲刺与压坡转弯；玩家进入威慑半径时减速、转头俯视、皇冠搏动增强。
4. **不破性能与门禁**：DrawCall ≤160、三角形 ≤1.2M、CPU 帧 ≤1.5ms；`npm run ci` 与 `npm run verify:ego` 保持全绿；行为层零逐帧分配、不新增系统注册项。

## 2. 现状与切入点

| 层 | 现状 | 切入点 |
| --- | --- | --- |
| 个体运动 | `BaseMathCreature.update()` → `CelestialOrbitEngine.sampleOrbit()`，开普勒 + 噪声漂移，已有 per-instance 轨道 | 在轨道解算前后加行为层，不改轨道契约 |
| 个体姿态 | 固定 `rotateZ(0.22 * sin(...))` 侧倾 + 轴向自旋 | 侧倾/俯仰改由行为档案增益驱动 |
| 巨兽运动 | `RiemannLeviathan.update()` → `MobiusFlightPath.sample()`，固定参数闭合导轨 | 新增 `LeviathanPilot` 二次机动层 |
| 调度 | `SystemRunner` + 8 系统 | 行为并入 `CreatureSystem` / `LeviathanSystem`，系统数不变 |
| 验收 | `npm run ci`、`npm run verify:ego` | 期望值不放宽，只补行为相关单测 |

## 3. Phase A — 个体行为层

### 3.1 新增文件

- `src/entities/behavior/BehaviorProfile.ts`
  - `BehaviorProfile`：`temperament`（curious / fearful / indifferent）、`speedBase`（0.65–1.55）、`speedWobbleAmp`、`speedWobbleOmega`、`wanderAmp`、`wanderOmega`、`reactRadius`、`reactStrength`、`rollGain`、`pitchGain`、`phase`。
  - `createBehaviorProfile(category, modelType, seed)`：FNV-1a 字符串哈希 + 整数雪崩哈希，输出确定性档案。
  - 性格投票带门类偏置：混沌/高维更好奇，数论更警觉，其余中性。
- `src/entities/behavior/CreatureBehavior.ts`
  - 实例级行为状态：独立行为时钟 `clock`、平滑反应权重 `reactWeight`、复用的 `Vector3` 临时量。
  - `tick(delta)`：`clock += delta * speedBase * (1 + speedWobbleAmp * sin(clock * speedWobbleOmega + phase))`。
  - `applyOffsets(position, tangent, playerPos, delta)`：
    1. 三个不可通约正弦合成游荡偏移（幅度 `wanderAmp`）；
    2. 玩家距离小于 `reactRadius` 时按平滑权重产生反应：好奇个体朝玩家偏移并转头，恐惧个体反向逃逸，冷漠个体不响应；
    3. 偏移直接作用于轨道解算后的位置与切线，轨道骨架不被破坏。
  - `rollAngle(elapsed)` / `pitchAngle(elapsed)`：由档案增益放大的姿态微动。
  - `spinScale`：自旋速度随速度基线缩放。

### 3.2 修改 `BaseMathCreature`

- 构造时以 `config.category / config.modelType / config.orbit.seed` 创建 `behavior`。
- `update()` 顺序改为：
  1. `behavior.tick(delta)` 推进个体时钟；
  2. `sampleOrbit(..., behavior.time, ...)` 用个体时钟解算轨道；
  3. `behavior.applyOffsets(...)` 叠加游荡/反应；
  4. `lookAt` 后叠加 `rollAngle` 与 `pitchAngle`，再按 `rotationSpeed * spinScale` 自旋；
  5. 同步 uniform。

## 4. Phase B — 黎曼威慑龙

### 4.1 新增 `src/core/flight/LeviathanPilot.ts`

- 内部持有独立 `MobiusFlightPath` 与 `pathTime`，每帧按 `speedMul` 推进：
  - `speedMul = 1 + 0.45 sin(0.07t) + 0.35 sin(0.23t) - 0.45 * deterrence`，形成慢巡游 + 快冲刺 + 威慑减速。
- 在导轨输出之上叠加：
  - **脊柱蜿蜒**：沿机体局部 X/Z 轴叠加反相位正弦横向摆动；
  - **俯冲/爬升**：低频起伏包络调制高度；
  - **威慑姿态**：玩家进入约 720 单位半径后，`deterrence` 平滑升至 1，四元数按权重 slerp 到“机头指向玩家”，巡游同步减速。
- 输出位置/速度/四元数，并返回 `deterrence` 供皇冠搏动联动；速度按 `speedMul` 缩放，供音频 Doppler 使用。
- 全部临时量实例级复用，零逐帧分配。

### 4.2 修改 `RiemannLeviathan` 与 `LeviathanSystem`

- `update(delta, elapsed, playerPosRender, playerVel)` 接入 pilot；`LeviathanSystem` 传入 `delta`。
- `updateCrown` 叠加 `deterrence`：皇冠额外放大、`uCrownPulse` 增强，形成“威慑时鼓胀发光”的龙形反馈。
- 保留 `syncWorld()`、共享 uniform 同步与既有皇冠双峰搏动。

## 5. Phase C — 验证

1. **单元测试（vitest）**
   - 行为档案确定性：同输入同档案；大量种子下速度/游荡参数有差异。
   - 个体时钟单调、速度乘数有界、连续小步长无跳变。
   - 好奇个体靠近玩家时产生朝向偏移，恐惧个体反向，冷漠个体位置偏移仅来自游荡。
   - `LeviathanPilot` 输出位置/速度/四元数有限且连续；威慑权重升降平滑。
2. **`npm run ci`**：typecheck + vitest + build + bundle 预算。
3. **`npm run verify:ego`**：114 个体 / 40 类 / 壳层 31-65-18 / LOD 切换 / DrawCall ≤160 / 三角形 ≤1.2M / 8 系统 / 0 运行时错误。
4. **EGO 实机观察**：个体轨迹与瞬时速度肉眼可辨；巨兽在玩家靠近时减速转头、皇冠增强；CPU 帧预算内。

## 6. 关键约束

- 零 GC：所有逐帧向量/四元数使用实例级或模块级临时量。
- 不改 `MODEL_ORDER`、`MODEL_CTORS`、壳层半径与注册表契约；行为在 `BaseMathCreature` / `CreatureFactory` 内注入。
- 不新增系统注册项；若未来新增，必须同步更新 `scripts/ego-smoke.js` 期望值而非放宽断言。
- 行为参数只影响运动与姿态，不改变模型几何、LOD 与音频族映射。
