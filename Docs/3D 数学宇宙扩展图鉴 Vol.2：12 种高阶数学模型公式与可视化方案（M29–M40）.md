## 2. 逐模型精确数学公式与可视化方案

### M29：陀螺面三周期极小曲面（Gyroid TPMS）
* **隐式数学方程**：
  在局部空间 $\mathbf{p} = (x, y, z) \in [-\pi, \pi]^3$ 内，Gyroid 的近似隐式等值面定义为：
  $$F(x, y, z) = \sin(x)\cos(y) + \sin(y)\cos(z) + \sin(z)\cos(x) = t$$
  限制在球形包络 $\|\mathbf{p}\| \le R_0$ 内，形成一座布满连通三维迷宫孔洞的生物珊瑚球（厚度壳体满足 $|F(\mathbf{p})| \le \delta$，其中 $\delta = 0.14$）。
* **几何生成与着色器方案**：
  * **推荐管线（Raymarching SDF）**：复用 `MATH_CREATURES_EXTENDED.md` 模板 4 框架，将 SDF 替换为球体截断的 Gyroid 壳距离场：
    $$d(\mathbf{p}) = \max\Big(\|\mathbf{p}\| - 1.35,\;\; \frac{|F(k\mathbf{p})| - 0.14}{k \cdot 1.6}\Big)$$
    其中空间频率 $k = 2.6$，并令 $t(u_{\text{time}}) = 0.25 \sin(0.5 \cdot u_{\text{time}})$ 令孔隙产生有机的收缩扩张呼吸感。
  * **色彩与光影**：孔洞深处呈现幽暗海藻绿（`#059669`），薄壁边缘折射电光青（`#22D3EE`）与纯白边缘高光；远距离（LOD 1/2）降级为预烘焙低面数球形孔洞网格或星点。

### M30：施泰纳罗马曲面（Steiner's Roman Surface）
* **数学参数方程**：
  实射影平面 $\mathbb{R}P^2$ 在 $\mathbb{R}^3$ 中带有 $6$ 个奇异夹点（Pinch Points）的四次代数曲面，参数 $u \in [0, \pi]$，$v \in [0, \pi]$：
  $$x(u, v) = \frac{1}{2}\sin(2u)\cos^2(v)$$
  $$y(u, v) = \frac{1}{2}\sin(u)\sin(2v)$$
  $$z(u, v) = \frac{1}{2}\cos(u)\sin(2v)$$
  等价隐式代数方程为：$x^2 y^2 + y^2 z^2 + z^2 x^2 - r x y z = 0$。
* **几何生成与着色器方案**：
  * 生成 $64 \times 64$ 参数网格，在三个正交自交轴上叠加 3 条细微的高亮光针（标示三条双重点自交线）。
  * 使用模板 1（Fresnel + 抗锯齿网格），四片鼓胀光瓣呈现落日琥珀橙（`#FB923C`）向玫瑰绯红（`#F43F5E`）的平滑过渡，自交核心区因双层叠加混合自然触发柔和白光。

### M31：门格海绵（Menger Sponge —— 3 阶递归晶格）
* **数学构造（三维康托集推广）**：
  将单位立方体 $[0, 1]^3$ 按 $3 \times 3 \times 3$ 等分，剔除中心方块及 $6$ 个面心方块（每级保留 $20$ 个子立方体）。第 $k$ 阶的盒计数分形维数为：
  $$D_H = \frac{\ln 20}{\ln 3} \approx 2.7268$$
* **几何生成与着色器方案**：
  * 递归展开至第 $3$ 阶（共 $20^3 = 8000$ 个微型立方体，剔除被完全内部遮挡的实例后仅剩约 $4800$ 个可见实例），全部打包为 **1 个 `THREE.InstancedMesh`**。
  * **动态分解呼吸**：在顶点着色器中按实例到几何中心的径向向量 $\mathbf{d}_i$，施加周期性极微弱的径向悬浮位移 $\Delta \mathbf{p}_i = 0.12 \sin(u_{\text{time}} - 2.0 \|\mathbf{d}_i\|)\,\mathbf{d}_i$，使整座分形方舟像活体机械阵列般脉冲搏动。
  * 颜色采用冷峻的冰川蓝（`#38BDF8`）与星云靛紫（`#818CF8`），立方体棱边采用基于 UV 的边缘高亮着色。

### M32：$E_8$ 李群根系投影（Gosset $4_{21}$ Polytope in $\mathbb{R}^8 \to \mathbb{R}^3$）
* **数学构造**：
  例外单李群 $E_8$ 拥有八维空间中最极致对称的 **240 个根向量**（模长均为 $\sqrt{2}$），由两部分组成：
  1. **112 个整数根**：$(\pm 1, \pm 1, 0, 0, 0, 0, 0, 0)$ 的全部坐标排列（$\binom{8}{2} \times 2^2 = 112$）。
  2. **128 个半整数根**：$\left(\pm \frac{1}{2}, \pm \frac{1}{2}, \dots, \pm \frac{1}{2}\right)$ 且负号个数为偶数（$2^7 = 128$）。
  当两个根向量满足内积 $\mathbf{r}_i \cdot \mathbf{r}_j = 1$（即欧氏距离 $\|\mathbf{r}_i - \mathbf{r}_j\| = \sqrt{2}$）时相连，共构成 **6720 条对称边**。
* **三维考克斯特平面投影算法**：
  * 选取 $E_8$ 的考克斯特（Coxeter）特征正交基向量 $\mathbf{u}_1, \mathbf{u}_2 \in \mathbb{R}^8$，再额外构造一个正交第三基向量 $\mathbf{u}_3 \in \mathbb{R}^8$，将 240 个八维点投影至三维：
    $$(X, Y, Z) = \big(\mathbf{r} \cdot \mathbf{u}_1,\; \mathbf{r} \cdot \mathbf{u}_2,\; \mathbf{r} \cdot \mathbf{u}_3\big)$$
  * 在渲染时仅保留外层与核心对称壳层的约 $1600$ 条精选主对称边（合并为单一 `LineSegments` 缓冲，启用极低不透明度 `AdditiveBlending`），并将 240 个根点渲染为 1 个 `InstancedMesh` 发光星核。
* **视觉与动画**：
  * 八重同心星环散发辉煌的圣殿金（`#FACC15`）与品红（`#EC4899`）光晕，在 GPU 顶点着色器中于第 4–8 维高维子空间执行缓慢的旋转混叠，令星盘内部的 240 颗星核如万花筒般精准交错流转。

### M33：仓本耦合振子星群（Kuramoto Coupled Oscillators on $S^2$）
* **数学方程**：
  在球面网格上分布 $N = 600$ 个发光生物振子节点，每个节点 $i$ 具有固有频率 $\omega_i \sim \mathcal{N}(\omega_0, \sigma^2)$ 与瞬时相位 $\theta_i(t) \in [0, 2\pi)$，遵循全局耦合动力学方程：
  $$\frac{d\theta_i}{dt} = \omega_i + \frac{K(t)}{N} \sum_{j=1}^{N} \sin(\theta_j - \theta_i)$$
  等价序参量形式（$O(N)$ 极速实时更新）：令 $R e^{i\Psi} = \frac{1}{N}\sum_{j=1}^N e^{i\theta_j}$，则 $\dot{\theta}_i = \omega_i + K(t) R \sin(\Psi - \theta_i)$。
* **几何生成与着色器方案**：
  * 让耦合强度 $K(t) = K_c + 1.8 \sin(0.25 t)$ 在临界同步阈值 $K_c$ 上下周期性缓慢摆动，使这团发光生物在“混乱无序闪烁”与“全群共振齐明”两种相态之间自发交替！
  * 每帧 CPU 仅需 $600$ 次标量三角运算更新实例属性 `aPhase`，着色器按 $\cos^{6}(\theta_i / 2)$ 控制节点亮度峰值，实现极其迷人的深海萤火同步共振奇观。

### M34：达德拉斯多涡卷混沌吸引子（Dadras Attractor）
* **数学方程**：
  $$\frac{dx}{dt} = y - a x + b y z$$
  $$\frac{dy}{dt} = c y - x z + z$$
  $$\frac{dz}{dt} = d x y - e z$$
  典型四涡卷参数：$a = 3.0$，$b = 2.7$，$c = 1.7$，$d = 2.0$，$e = 9.0$。
* **几何生成与着色器方案**：
  * RK4 积分采样 $6000$ 点形成四个相互缠绕的对称电弧羽翼；采用模板 3 粒子流着色器，沿轨线发射靛紫（`#6366F1`）与粉红（`#F472B6`）高速双色电脉冲。

### M35：黎曼 $\zeta$ 函数临界带复相丝带（Riemann $\zeta(s)$ Critical Strip Ribbon）
* **数学方程与定位**：
  作为围绕**黎曼猜想终极巨构**巡逻的“护卫幼体生物”，直接可视化解析延拓后的临界带 $s = \sigma + i t$（$\sigma \in [0.05, 0.95]$，$t \in [10, 50]$），通过交错迪利克雷 $\eta$ 函数在 CPU/GPU 上高效求值：
  $$\zeta(s) = \frac{1}{1 - 2^{1-s}} \sum_{n=1}^{M} \frac{(-1)^{n-1}}{n^s}, \quad \text{Re}(s) > 0$$
  将其映射为一条盘旋的三维势能起伏光带：
  $$X = 2.4(\sigma - 0.5), \quad Y = \frac{t - 30}{12}, \quad Z = 0.65 \ln\big(1 + |\zeta(\sigma + it)|\big)$$
* **着色器视觉方案**：
  * 采用**复数域着色（Domain Coloring）**：片元色相严格由辐角 $\arg(\zeta(s)) \in [-\pi, \pi]$ 映射，并在虚部 $t = 14.1347,\, 21.0220,\, 25.0109,\, 30.4249,\, 32.9351,\, 37.5862,\, 40.9187,\, 43.3271,\, 48.0052$ 等前 $10$ 个非平凡零点处（$\sigma = \frac{1}{2}$）镶嵌纯白高能脉冲星核，直观呼应宇宙中心的黎曼巨构。

### M36：科斯塔极小曲面（Costa's Minimal Surface —— 数值近似网格）
* **数学构造**：
  亏格为 $1$、带 $3$ 个端（1 个悬链端 + 2 个平面端）的无自交嵌入极小曲面，由魏尔斯特拉斯椭圆函数 $\wp(z)$ 在正方形格点 $z \in (0, 1)^2$ 上定义。
  * **落地工程实现**：采用双周期傅里叶-魏尔斯特拉斯截断级数在初始化时预计算 $64 \times 64$ 网格（截断奇点半径 $0.08$），归一化为直径 $2.0$ 的三层优雅穿孔马鞍拓扑光杯。
* **着色器视觉方案**：
  * 采用模板 1，双面呈现湖蓝（`#0EA5E9`）与薄荷绿（`#34D399`）渐变，高曲率鞍点边缘自动泛白，沿网格主曲率方向流动柔和微光。

### M37：三维二十面体准晶体（3D Ammann-Kramer-Neri Quasicrystal）
* **数学构造（6D 切投影法 Cut-and-Project）**：
  选取正二十面体 $6$ 条对角轴构成六维超立方晶格 $\mathbb{Z}^6$ 向三维物理空间 $\mathbb{E}_\parallel$ 与三维垂直空间 $\mathbb{E}_\perp$ 的正交投影矩阵 $\mathbf{M}_\parallel, \mathbf{M}_\perp \in \mathbb{R}^{3 \times 6}$（基于黄金比例 $\tau = \frac{1 + \sqrt{5}}{2}$）：
  $$\mathbf{e}_1 = \frac{1}{\sqrt{1+\tau^2}}(1, \tau, 0), \;\; \mathbf{e}_2 = \frac{1}{\sqrt{1+\tau^2}}(-1, \tau, 0), \;\; \dots$$
  筛选所有满足垂直空间投影落入菱形三十面体接受窗 $\mathbf{M}_\perp \mathbf{n} \in W_{\text{triacontahedron}}$ 的晶格点 $\mathbf{n} \in \mathbb{Z}^6$，并将其物理空间坐标 $\mathbf{M}_\parallel \mathbf{n}$ 与相邻键长连线输出。
* **视觉与动画**：
  * 生成约 $350$ 个顶点的非周期五重对称星晶网络（`InstancedMesh` 发光晶核 + `LineSegments` 晶键），兼具严密秩序与永不重复的神秘美感；浅玫瑰红（`#FDA4AF`）与天星蓝（`#60A5FA`）沿径向层壳交替闪烁。

### M38：磁偶极子范艾伦等离子环（Magnetic Dipole Flux Cage）
* **数学方程**：
  在球坐标 $(r, \theta, \phi)$ 下，三维磁偶极子场线族严格满足 $L$-壳层方程：
  $$r(\theta) = L \sin^2(\theta), \quad \theta \in [0.18, \pi - 0.18]$$
  磁场强度幅值按偶极衰减：$B(r, \theta) \propto \frac{\sqrt{1 + 3\cos^2\theta}}{r^3}$。
* **几何生成与着色器方案**：
  * 在 $3$ 个磁壳层 $L \in \{0.65, 1.0, 1.45\}$ 上各生成 $16$ 条方位角均布的闭合偶极磁力线细管（合并为单 Mesh），另叠加 $1200$ 个沿磁力线做螺旋拉莫尔（Larmor）往复弹跳的极光带电粒子。
  * 粒子在接近南北两磁极（磁镜点）时速度减缓并爆发青蓝（`#06B6D4`）与紫罗兰（`#A78BFA`）极光闪烁。

### M39：ABC 三维贝特拉米流（Arnold-Beltrami-Childress Flow）
* **数学方程**：
  不可压缩欧拉方程的经典三维定常精确解（速度场与其旋度处处平行 $\nabla \times \mathbf{u} = \mathbf{u}$，流线呈现混沌拉格朗日湍流）：
  $$\frac{dx}{dt} = A \sin(z) + C \cos(y)$$
  $$\frac{dy}{dt} = B \sin(x) + A \cos(z)$$
  $$\frac{dz}{dt} = C \sin(y) + B \cos(x)$$
  经典混沌系数：$A = \sqrt{3}$，$B = \sqrt{2}$，$C = 1$，约束在球形周期容器内。
* **几何生成与着色器方案**：
  * 在球域内投放 $2500$ 个带 6 节拖尾的流线微粒，每帧（或预烘焙循环轨迹表）沿 ABC 速度场平滑游动，颜色按局部涡度/流速在琥珀金（`#F59E0B`）与深海碧绿（`#10B981`）间流转，酷似一座在太空中自行搅动洋流的混沌海葵。

### M40：多重半扭莫比乌斯超环带（Twisted $k$-Half-Twist Möbius Band）
* **数学方程**：
  取半扭转次数 $k = 3$（奇数次仍为单侧不可定向曲面），参数 $u \in [0, 2\pi)$，$v \in [-0.38, 0.38]$：
  $$x(u, v) = \left(1 + v \cos\frac{k u}{2}\right)\cos u$$
  $$y(u, v) = \left(1 + v \cos\frac{k u}{2}\right)\sin u$$
  $$z(u, v) = v \sin\frac{k u}{2}$$
* **几何生成与着色器方案**：
  * 生成 $160 \times 16$ 丝带网格，沿单侧边界循环发射一对相向奔跑的高能流光脉冲（需绕行 $4\pi$ 方能回到同侧起点），边缘以品红（`#EC4899`）与电青（`#22D3EE`）双线勾勒，形似在宇宙中优雅翻滚的无限光带魔鬼鱼。
